# Privacy Analysis

## Organization of the repository
- **code** folder: for the source code
- **data** folder: for input data required for the project as well as output data collected.
- **results** folder: holds results files generated as part of the project
- **thesis** folder: contains the latex sources + PDF of the final thesis.
- **presentation** folder: contains the sources of the presentation 
- **literature** folder: contains research papers read for the thesis
- **notes** folder: notes throughout the journey
